# Project guidance

- Present Yiyi Qian as an Artist + XR/HCI Researcher; keep art practice and research equally visible.
- Preserve the contemporary-art portfolio × academic archive × editorial publication aesthetic.
- Prefer typography, whitespace, image composition, and quiet interaction over decorative UI.
- Do not introduce SaaS styling, repetitive rounded cards, bright gradients, neon effects, or technology-demo visuals.
- Keep the site static and dependency-light. Do not add a client framework or large UI/animation library without a clear requirement.
- Use the Works categories `Cinematic VR`, `Interactive Media`, and `Research Projects`; use tags for topics.
- Project pages must prioritize Artwork / Experience → Research Question → Creative Process → Reflection / Outcome.
- Never invent publications, awards, exhibitions, affiliations, research findings, or project claims. Mark missing information clearly.
- Keep academic identity fields extensible for ORCID, Google Scholar, DOI, conferences, CV, and consented reference information.
- Preserve semantic HTML, keyboard navigation, focus states, contrast, alt text, and `prefers-reduced-motion` behavior.
- Preserve mobile layouts and test approximately 1440, 1024, 768, and 390 pixels after visual changes.
- Do not delete or rewrite user content casually. Keep unrelated sections untouched for small requests.
- Reuse existing components and content schemas before adding new architecture.
- Before major redesigns or structural changes, ensure the Git state is recoverable.
